# JARVIS Holographic Simulation Engine

Advanced AI-driven holographic simulation engine built with Three.js, MediaPipe, and WebXR.

## Quick Start

```bash
cd holographic-engine
npm install
npm run dev
```

## Features

- **Particle Engine**: 200k+ particles with GPU morphing.
- **Gesture Control**: MediaPipe hand tracking for spatial interaction.
- **AI Commands**: Natural language intent interpretation.
- **Physics**: Real-time mathematical simulation models.
- **VR Mode**: Immersive WebXR support.
- **Holographic UI**: Floating diagnostic and control panels.

## Controls

- **Pinch**: Grab and drag holographic structures.
- **Spread**: Zoom in/out of the simulation.
- **dat.gui**: Manual controls for rendering parameters.
