# JARVIS-X (Aura Core)

This is the advanced frontend interface for **JARVIS-X**, integrated with real-time OS monitoring, AI-powered project tools, and a dynamic 3D VRM avatar.

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS)
- Bun or npm

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

## 🛠️ Integrated Features
- **3D Avatar (VRM)**: Real-time rendered avatar with reactive animations.
- **System Watcher**: Live tracking of CPU, RAM, and Active Window.
- **Project Tools**: Manage your filesystem and IDE directly from the UI.
- **Smart Console**: AI-powered command center for code generation.

## 📡 Backend Sync
Ensure your **JARVIS Backend** is running (`python main.py`) before starting this frontend to enable full system synchronization.
